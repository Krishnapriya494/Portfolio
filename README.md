Personal Portfolio Website

This is my personal portfolio website developed to showcase my projects, technical skills, and areas of interests. The portfolio is designed with a modern, responsive user interface and incorporates various front-end design techniques to enhance user experience.

The website includes sections such as Home, About Me, Skills, Projects, and Contact, providing a structured overview of my academic work and technical capabilities.

Key features of this portfolio include:

- Responsive design for different screen sizes
- Smooth scrolling navigation
- Interactive hover effects and transitions
- Card-based layout for projects and skills
- Gradient backgrounds and modern UI styling

This portfolio was built using the following technologies:

- HTML5
- CSS3 (Flexbox and CSS Grid)

Setup instructions

- Clone the Repository
- Navigate to Project Folder
- Open the Project

How to Run the Project

- Open the folder in VS Code
- Right click on index.html
- Click "Open with Live Server"

The purpose of this project is to present my work in a visually appealing and organized manner, while also demonstrating my understanding of front-end web development concepts.
